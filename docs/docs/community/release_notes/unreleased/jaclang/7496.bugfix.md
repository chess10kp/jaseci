- **Fix: `jac lint` no longer runs the AST-rewriting auto-lint pass**: the report path (`jac lint`, `JacProgram.jac_file_linter`) used `JacAutoLintPass` (report_only=False), performing the full auto-lint mutation pass and discarding the result. It now uses `JacLintCheckPass` (report_only=True), matching `jac check`. The report-only pass emits every warning it detects directly from the source — including the auto-fixable ones (`staticmethod`-to-`static`, combine `has`, `__init__`-to-`init`, empty-parens removal, and the other rewrite hooks) that a `report_only` short-circuit previously dropped from `jac lint` and the LSP/MCP diagnostics path. The only warnings it does not surface are the second-order ones the mutation pass emits about code it just synthesized (e.g. `combine-has` on `has` fields generated from `useState`, or `simplify-ternary` on a ternary left self-identical by a `hasattr` rewrite); reporting those would point at source that does not exist until the fix is applied. The lint pass is significantly faster and `jac lint` is faster end-to-end over the tracked tree.
