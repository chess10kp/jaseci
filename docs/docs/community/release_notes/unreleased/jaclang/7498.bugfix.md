- **Fix: `str()` of an `any`-boxed scalar on the native path stringified the type tag, not the value**: on the native (LLVM) backend `any` lowers to a tagged `JacVal { i8 tag, i64 payload }`. `str()` had no case for that struct and fell through to the integer fallback (`snprintf("%ld", <JacVal>)`), which read the tag byte (0=int/1=float/2=str/7=bool/8=none) instead of the boxed value, diverging from the CPython path. `str()` now dispatches on the runtime tag and stringifies the actual scalar (the `str` case returns an owned `rc_alloc` copy so the container's original string is not freed by the caller).
