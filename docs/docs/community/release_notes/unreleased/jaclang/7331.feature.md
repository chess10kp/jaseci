- **`jac prune`**: Compiler-backed dead-code cleanup - report findings, extract a SQLite fact store, preview/apply safe span edits with a validation gate, and run an advisory agent loop for structural redundancy (report-only).
- **`jac prune reuse`**: Structural-duplicate detection over the compiler forest. Hashes each callable's normalized body (byte-identical and constant-abstracted), groups impl-annex-aware clone candidates with class-hoist rollups, ranks them by payoff, and emits span-cited evidence packets (`--group <id>`) for a consuming agent to adjudicate. `--fuzzy` adds a token-overlap tier (Jaccard over k-gram shingles, default threshold `0.8`) that surfaces gapped/Type-3 near-clones - bodies that drifted by an inserted guard or one extra statement - which the exact and structural hashes miss. Report-only by construction: the tool loads no model and applies nothing.
- **`jac prune` reuse advisories (opt-in)**: Two report-only Tier-3 detectors catch duplication that body-hashing misses. `--recipe duplicated-constant-blobs` flags a string/collection literal (value-hashed, so quote style is ignored) repeated across ≥2 sites above a size floor; `--recipe duplicate-docstrings` flags an identical docstring or byLLM `sem` string on ≥2 distinct symbols (decl+impl on one symbol does not count; docstrings and `sem` strings with the same text group together).
- **`jac prune` module-cohesion advisory (opt-in)**: `--recipe module-cohesion` reports two LCOM-style seam signals over the symbol reference graph already in the fact store - a *split* candidate (a module whose internal symbols form ≥2 clusters with no edge between them) and a *merge* candidate (two modules cross-referencing each other more than either references itself). Report-only seam-review advisories, sorted below all actionable findings; splits cite one symbol per cluster (`sym:<id>`), merges cite the two modules (`mod:<path>`). Pure query - no schema change or re-extraction.
