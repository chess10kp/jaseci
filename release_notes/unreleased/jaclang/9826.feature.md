- **`jac update --self`: the binary updates itself**: running `jac update --self` resolves the newest GitHub release (or a pinned `--release <tag>`), downloads this platform's `jac` binary, verifies the published sha256, and atomically replaces the running launcher -- already-running processes keep their version and new invocations pick up the update, no reinstall script needed. It refuses the cases it must not touch: plain interpreter sessions, linked dev binaries (`zig build -Ddev`), unwritable install locations, and hosts no release ships.
