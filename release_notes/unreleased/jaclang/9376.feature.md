- **Opt-in experiment: escape-proven function-local list headers in the frame
  (`JAC_NATIVE_STACK_LIST_HEADERS=1`)**: For issue #9376, `RcFactsPass` gained
  an escape stamp (`na_list_stack_ok`) for function-local list displays — no
  return, no aliasing, no user-call arguments, re-binding only from other
  displays — and the native backend can then construct the list header in a
  frame `alloca` (refcount slot set to the static sentinel), keeping only the
  data buffer on the heap, with scope-exit/loop/overwrite/last-use releases
  routed through a new data-only release helper. Controlled interleaved A/B
  benchmarking against the `#9362` baseline measured the design cycle-neutral
  on pure append churn and slightly negative on read-mixed churn under
  `clang -O2`; the prototype's 55% figure did not reproduce
  (`docs/architecture/native-list-append-performance.md`). Validation also
  surfaced a layout-sensitive crash in the data-only release routing, so the
  feature ships **off by default** behind the environment variable and its
  tests enable it explicitly. Measured behavior with the gate unset is
  unchanged from the previous release.
