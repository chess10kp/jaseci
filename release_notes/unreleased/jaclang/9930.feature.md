- **JacPython: more CPython objects ported to native Jac**: `range`, `slice`/`Ellipsis`, `enumerate`/`reversed`, the sequence and callable iterators, `SimpleNamespace`, `bool`, cells and capsules now come from native Jac instead of CPython's C. They keep CPython's freelists, inline refcounting and direct slot calls, so they run at C speed. The native backend now calls through C function-pointer fields (`p.field(args)` on a `ptr[T]`) and reads and writes fields through `ptr[T]`.
