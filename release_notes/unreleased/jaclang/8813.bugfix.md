- **Fix: pure-jac installs now sync transitive Python deps into the venv**: a pure-jac dependency's own Python requirements were resolved and recorded in `jac.lock`, but never installed, so code importing them failed at runtime until a separate bare `jac install` happened to run. The commit step of `jac install jac:` / `jac update` now installs the exact resolved closure (`name==version`, root-declared and transitive) into the project venv before the new generation is published, and a failed sync aborts the whole install transaction instead of leaving a broken tree. `--frozen` replays stay store-only (they promise no network).
