- **Compiler: One JIR cache entry per compiler-source module, not one per requesting context**: Compiler-internal and stub-like modules omit the requesting `cache_scope` identity from their JIR cache keys and file names, mirroring how their environment fingerprint already omits project context. Apps and test directories that import compiler-source modules now share one warm-cache entry instead of recompiling and storing an identical copy per entry-point context; project and app modules keep full per-application cache isolation.
