- **Test Runner: Embedded Postgres databases are now reclaimed after each test**: The pytest plugin sweeps each test's derived database family (and temp base directory) as soon as the next context starts, and collects the rest at session end -- including under xdist. Test runs no longer accumulate thousands of databases in the shared embedded cluster (`~/.cache/jac/pg/main`), which made crash recovery -- and therefore subsequent runs -- progressively slower. Only plugin-created temporary stores are cleaned up; real project databases are never touched.
- **New: `jac db gc`**: The embedded runtime now records which base directory each derived database came from. `jac db gc` drops registered databases whose base directory no longer exists (crashed runs, finished tests, one-shot scripts), so any workflow -- not just pytest -- can reclaim embedded-cluster space. Live project directories are never collected.
