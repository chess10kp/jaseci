- **Feature: native `math` becomes a bundled `na_stdlib` module**: The native codespace's `math` support moved from compiler intercepts to a pure-Jac `na_stdlib/math.jac` surface over an `_math_native` libm FFI floor, providing roughly fifty CPython-congruent functions with error-message parity, and supporting `import from math { ... }` from-imports.
- **Feature: native `cmath` bundled module and complex arithmetic**: The native codespace gains `na_stdlib/cmath.jac`, a pure-Jac port of CPython's `cmathmodule.c` algorithms (special-value tables included) over the `_math_native` libm floor. Supporting it, the native backend now lowers `complex` function signatures, `.real`/`.imag` attribute access, `**` with complex operands (exact integer-exponent fast path plus the general `exp(w·log z)` path), and CPython's robust complex-division algorithm.
