- **Breaking: dependency store hashes and pre-v2 `jac.lock` files are invalidated**: the content store now hashes dependency trees with a directory-aware algorithm (file *and* directory entries), so every cached tree written by a previous version becomes unreachable and is re-fetched on the next `jac install`. Lockfiles written by earlier versions (`version = 1`) are no longer replayable: `jac install --frozen` on such a lock now fails with "jac.lock is a pre-v2 lockfile; run `jac install`" instead of a misleading fingerprint error. Run `jac install` once per project to write the v2 graph (with a `manifest_fingerprint` pin) and repopulate the store; after that, `--frozen` replays verify the manifest against the lock's fingerprint.
